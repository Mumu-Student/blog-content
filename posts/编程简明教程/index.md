# 编程
编程，也就是编写程序，使用编写好的程序去处理数据，使工作效率大幅度提升。

## 编写
编写，你可以用word，记事本，你也可以用专门的软件来编写程序，编写完将文件后缀换为特定js、ts、c、css等后缀，就可以交给计算机运行，这就是编写。

## 程序
程序，程序泛指任何网站、软件、脚本、系统之类的东西，但，不管是什么，程序只有两个部分，数据和函数（函数也可以说是一种数据，这里就不细说了，关系不大）。

只要理解这两个概念，你就知道整个编程体系的基石了，所有应用程序都是由数据和函数搭建起来，一层一层封装的。

1、数据
数据的本质很简单，就是保存在内存条或者硬盘上的电子，0和1的不断排列，组成了你现在看到的视频画面、点赞数量等；程序员指的数据是字符串、数组、对象等；工厂指的数据产品数量、工人工资等

2、 函数
函数就是  输入数据 → 处理数据 → 输出结果 的一段代码，这里的“段”，可能指的是一行代码，也有可能指的成百上万行代码


# 编程的难易
编程的主要工作，就是编写函数去处理数据，它的难度，由数据量的大小及处理逻辑的复杂程度决定
